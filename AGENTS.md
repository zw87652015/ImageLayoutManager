## Platform, startup, packaging
- Single-window routing (`src/app/instance_router.py`): each window owns a `QLocalServer` `ILM-<user>-<pid>` + registry file `<pid>.instance` under `AppLocalDataLocation/instances` (mtime = last focus). A launch with a file argv forwards `{"open": path}` to the most recently focused live instance (stale entries deleted) and exits before building UI; receiver = `MainWindow.open_external_path`. `--plot-editor` dispatch happens earlier and is unaffected.
- `main.py` must keep `WA_DeleteOnClose` on the `MainWindow`: without it, closing a session with a `bundle_workdir` crashes natively in sip teardown.
- macOS: `main._install_qt_message_filter` drops only Cocoa accessibility-bridge warnings. `theme.apply_app_palette` pins native chrome to the app theme — always use it, never bare `app.setPalette(build_palette(...))`.
- QtSvg doesn't split `font-family` lists: SVG assets must name one existing family (a list triggers a slow font alias scan).
- Windows packaging: Qt DLLs only under `_internal/PyQt6/Qt6/bin` (no duplicate top-level `Qt6*.dll` from Conda); Inno Setup's targeted `[InstallDelete]` removes obsolete top-level Qt DLLs on upgrade — keep it limited to those files.
- macOS packaging (`build_onefile_macos.py`, run with `.venv/bin/python`): generated spec has GUI + `imagelayout-cli` EXEs → one COLLECT → one BUNDLE. GUI EXE must stay first (becomes `CFBundleExecutable`). COLLECT inherits `console` from the last EXE, so BUNDLE's `info_plist` must set `LSBackgroundOnly=false`/`NSHighResolutionCapable` explicitly; the build fails if Info.plist regresses. Signing: `--codesign-identity`/`MACOS_CODESIGN_IDENTITY` (Developer ID Application), `--bundle-id` (default `com.zw87652015.imagelayoutmanager`); outer bundle re-sealed without `--deep`, `_verify_signature` fails on unsigned/ad-hoc nested Mach-O. `--notary-profile`/`MACOS_NOTARY_PROFILE` notarizes, staples and writes the zip + SHA-256.

## Canvas
- Default viewport is a QWidget (`QOpenGLWidget` was ~4× slower to pan); `ILM_CANVAS_OPENGL=1` opts back in for comparison only. The viewport uses `WA_OpaquePaintEvent`, so `CanvasScene.drawBackground` must fill the entire exposed rect; keep pixels correct after pan/zoom at high DPI.
- **Never connect anything to `QGraphicsScene.changed`** on the canvas scene: it switches Qt to its legacy update path and leaves stale pixels. Rulers refresh from mouse moves, `selectionChanged` and `_refresh_and_update`.
- Programmatic selection uses `CanvasView.reveal_selection()` (minimal animated pan only when outside the viewport margin); never reintroduce an unconditional `centerOn`.
- "Actual Size (100%)" is physical: px/mm from `QScreen.physicalDotsPerInch()` × per-monitor QSettings `display_calibration/<screen key>`. Transform m11 stays px-per-mm everywhere.
- Row/cell '+' buttons are screen-constant and resized in place by `_relayout_add_buttons`.
- PiP handle dragging relies on `CanvasScene.mousePressEvent` skipping PiP dismissal for the pressed cell and `CellItem.shape()` including `_selected_pip_handle_hit_rects` (handles outside `rect()`).
- Touch zoom (status-bar group, `QPinchGesture`) is user-verified only; don't add UI tests for it.

## Layout
- Grid modes (`project.grid_mode`): "Fill Page Width" = `stretch`, "Match Cell Size" = `fixed`. Stretch row height = (content width − (n−1)·gap) / Σaspects. Fixed: unit = (content width − (max−1)·gap) / max over rows; a k-column row is k·unit + (k−1)·gap wide, aligned by Row Alignment, height k·unit / Σaspects.
- Auto Layout with out-of-cell labels models each cell slot width = a·h + s (s = side strip + gap; containers combine children, mirroring `_layout_subcells` hoisting via `_wants_outer_edge`): row H = (avail − Σs)/Σa. Page height uses the engine's `_row_label_strips`, `_band_slot_assignment` and group-label gutters. **Any engine strip-geometry change must be mirrored in `AutoLayout.optimize_layout` or Auto Layout letterboxes.**
- Column dividers come only from `LayoutResult.col_slots` and each edits only its own row's `column_ratios`.
- Cell Gap (Project Settings and `Inspector.cell_gap_spin`) both emit `{"gap_mm": v}` → `ChangeGapCommand` (re-fits rows/page height in one undo step; no re-fit without images or in freeform).
- Auto-sentinel spin boxes (`AutoDoubleSpinBox`) show/step from effective values supplied as `_effective_*` payload keys built from `scene._last_layout_result`.

## Layers panel and selection
- Grid mode: cells grouped by row/column, **not** draggable (z_index meaningless). Freeform: flat list that *is* the z-stack (top = frontmost; sort `(z_index, creation index)` desc). Drops emit `reorder_requested(dragged, target, place_above)` → `ReorderZIndexCommand` (renumbers leaf z_index to rank) or `ReorderPipItemsCommand` (`cell.pip_items` order is the stack, last = frontmost); same-slot drops are skipped. PiPs are draggable in both modes.
- Selection invariant (`_select_cells_by_ids`): picking a PiP row also selects its parent `CellItem` and deselects PiPs on other cells; picking a cell clears every `_selected_pip_id` (a stale id routes `_on_selection_changed` to the PiP inspector). Run under a scene `QSignalBlocker` with one `_on_selection_changed()` after.
- "Reveal Image Source" opens the *current resolved* path (zoom PiP → parent cell's path), never `original_source_path`; re-check `isfile` at trigger time.
- `image_proxy.image_format_name()` is the single source for format badges/rows; keep Inspector captions short (narrow column), explanations in tooltips.

## Labels
- New labels default to 12 pt, zero offsets.
- Selected-Text/Label controls edit **only the selected label**; font/size/weight edits set `style_locked=True` (implicit, no checkbox), and both tier sync functions skip locked items. "Apply Style to All" (`apply_style_to_group`) writes the tier defaults (`label_*`/`title_label_*`/`corner_label_*`) and members and clears locks in one undo macro; corner labels are their own group. "Reset to Tier Style" emits a `label_tier` change; a tier change never locks.
- Per-label overrides `TextItem.label_align/label_valign/label_offset_x/y` (schema 3; `None` inherits). Resolve only via `Project.effective_label_align/valign/offsets` and `label_strip_is_vertical`. `src/utils/label_strip_render.py` is the single strip renderer for canvas/PNG/PDF; alignment applies inside the rotated frame. "Apply Position to All" clears all strip-label overrides in one macro.
- `LabelAlignPicker`: re-selecting the current slot emits nothing (no no-op undo).
- Auto Above-Cell Labels toolbar dropdown uses its own menu (Above/Below/Left/Right only); don't reuse the Layout placement menu (includes In-cell).
- Split strip labels (schema 7, `TextItem.sub_labels`/`sub_label_splits`, helpers `src/utils/sub_labels.py`): 2–8 segments. Numbering (`src/utils/auto_label.py`) counts only active panel-tier split labels on leaf strips: flat = one letter per segment; hierarchical = child numbers with full ancestry prefix (B-i) regardless of `label_sub_prefix_parent`; in-cell and title-tier splits never consume numbers. `SetSubLabelsCommand` is the single undo step; export never shows divider guides.
- Selected Text content stores line breaks as `<br>` (`src/utils/text_content.py`).

## Typography
- `Project.typography_mode` (schema 4): `"points"` (new projects: `font_size_pt` are real final-figure points via `src/utils/typography.py`) vs `"legacy"` (schema 0–3; stamped on migration; schema-4 files with missing/invalid mode are rejected, never reinterpreted). Legacy `font_size_pt`/`label_font_size` are **not** points (24-unit reference box, ~1.8 mm per unit). Math text and text-size groups are true points in both modes. Scale bars carry `scale_bar_text_size_mm` (legacy) and `_pt` (points).

## Text size matching
- Text groups (`Project.svg_text_groups`, `font_size_pt`) are final-figure points. `src/utils/panel_scale.py::panel_mm_per_unit` is the single source for mm per image unit; both pipelines divide by it.
- SVG: `svg_text_utils.get_svg_override_bytes_for_cell`; raster: `raster_text_utils.build_raster_override_spec` + `apply_raster_text_overrides`. Exporters use `text_overrides.overrides_for_cell`; the canvas puts overrides in the per-cell fingerprint and `ImageProxy` caches per (path, content-hash).
- Group overrides are written in SVG **user units** (`font-size:<n>px`), never `pt` (QtSvg resolves pt at ~1.24 px/pt → ~7% small). Per-cell `svg_normalize_text` still writes `pt` (changing it resizes existing figures).
- Effective sizes: `svg_text_rows`/`svg_text_effective_sizes`; read keys before `_positioned_text_runs`. Reflowing native plots change keys with cell size, so membership is per rendered bytes. The entry point lives in the Inspector's SVG Text Normalization section, not under the Reflow card.
- The exact contract is em size on the page; glyph-ink differences between QtSvg and raster are rasteriser-dependent, not bugs. `ink_ratio_for_text()` is character-dependent (don't revert to a 0.72 constant).
- Match Text Size windows (SVG + raster) share `src/app/text_group_chips.py`. Raster regions join groups via `region.group_id`, not `group.members`. A whole window session is ONE undo step (`text_match_session.SessionRecorder` → `TextMatchSessionCommand`, first redo is a no-op; `refresh()` calls `rebase()` so external edits are not recorded). Revert baseline is per image per app run (`MainWindow._text_match_baselines`), and `scoped_revert` affects only that image. Context item keys `ctx_svg_text_inspector`/`ctx_raster_text_inspector` = "Match Text Size…"; keep help/tutorial copy in sync.
- OCR backends: `src/utils/raster_text_ocr.py`, default/shipped `rapidocr` + `onnxruntime` (Preferences → Text Detection).
- Raster safety (`analyze_region`) judges a box's own interior; `_classify_text_pixels` keeps only components reaching the shared baseline (others → `foreign_excluded`, left un-erased); floating blobs are rescued as text using OCR per-character boxes (`RasterTextRegion.chars`), else geometry rules.
- Rotated raster text (schema 8, `angle` in (-90, 90]): when ≠ 0, `x/y/w/h`/`chars` live in the text frame (`src/utils/raster_text_frame.py`); within 5° of 0/±90 snaps to 0.

## Export and clipboard
- Raster output has one path: `ImageExporter.render_image(project, fmt=, transparent=)`; `export()` saves it, `render_to_qimage()` is the opaque-white form. Copy as PNG (`clipboard_export.copy_project_png`): alpha PNG under `PNG_WINDOWS_FORMAT` (Windows) / `image/png`, plus an opaque RGB32 image via `setImageData` (RGB32 avoids a clashing "PNG" format).
- PDF images (`src/export/pdf_images.py`): Qt re-encodes every raster as JPEG, so rasters are logged (`PdfRasterLog`) and after `painter.end()` each Qt image XObject is replaced by xref with PyMuPDF (matched by draw order vs xref order, guarded by size + 16×16 signature; cropped cells log the drawn sub-rect). `lossless` (default) = Flate or original JPEG bytes; `lossy` = JPEG at `jpeg_quality` (4:4:4 at ≥ 90). Problems are structured `PdfIssue(code, params)` localised by `format_issue` (`pdf_issue_*` keys); lossless runs an audit and sets `report.lossless_verified`. SVG-embedded data-URI images are optional log entries. Known gaps: `<img>` in rich text, rasters in SVG patterns; Pass-2 PDF/EPS stamps are outside the audit.
- Clipboard paste (`src/utils/clipboard_paste.py`): images into selected cell(s) (one macro), text → floating `TextItem`. Bitmaps stored content-addressed under `<figpack cache>/pasted_images`, which `cleanup_orphans` must skip; plain `.figlayout` saves relocate them to `<name>_assets/`. Web-image links are never fetched. Office/GVML resolves the original embedded picture bytes.
- Vector marks (schema 6 `Project.marks`, page mm): `mark_geometry.py` (math) + `mark_render.py` (single QPainter source for canvas and all exporters); commands `Add/DeleteMarks/MarkPropertyChange/ReorderMarksCommand`; agent tools `mark_add/update/remove/reorder`. Regular polygons are stored as plain closed polygons (regularity detected from geometry). Draw mode locks all non-mark items (`_apply_draw_lock`, re-applied after `refresh_layout`/`refresh_export_region`); it is mutually exclusive with preview, export-region and crop modes. Mark clipboard MIME `application/x-ilm-marks+json`, one `AddMarksCommand` per paste.

## Project compatibility
- `PROJECT_SCHEMA_VERSION` (`src/model/migrations.py`) is independent of `APP_VERSION`; `schema_version` written by `to_dict()`, `file_version` = writer app. Missing `schema_version` = legacy 0.
- All `Project.from_dict()` validate/migrate copied input; bundle unpack validates before extracting. Future schemas raise actionable errors; a newer writer using a supported schema is allowed. Loading never rewrites the source; saves are atomic.
- Every schema bump: increment the version, register `SCHEMA_MIGRATIONS`, add `DOWNGRADES[N]` (N→N−1, Qt-free in `src/model/downgrade.py`, returns `(dict, [(code, count)])`, recurses `children`), a `SCHEMA_FIRST_RELEASE` entry, a `DOWNGRADE_TARGETS` label once released, `save_older_issue_<code>` i18n keys, and compatibility fixtures. Never just relabel old data.
- "Save Copy for Older ILM…" never touches the open tab. Saving over an older-schema source shows the "Update project format?" warning (`save/skip_upgrade_warning` opt-out).
- First save of a never-saved project shows `SaveFormatDialog` (.figlayout default vs .figpack); Save As skips it. Qt-free helpers in `src/app/save_format.py`.
- Export All Source Images snapshots paths first, copies the current resolved `image_path` (never `original_source_path`) on a worker; never saves, relinks, dirties or releases the bundle workdir.
- Bundle unpack (`_resolve_resource_paths`) resolves paths purely lexically — never probe the filesystem for dead originals (caused freezes/crashes); >1 match raises `BundleError('ambiguous_resource')`.
- External writes into an open tab's `bundle_workdir` mark it `assets_dirty` + unsaved; ILM's own hot-reload copies are excluded via `_hot_reload_self_writes`.

## Manual plot alignment
- `PlotAlignmentDialog` works on isolated drafts (`build_candidate()` deep-copies). Cancel never mutates the live model, undo stack or source bytes; Apply pushes one `SetPlotAlignmentCommand` after checking the originating tab/project is still live. Never shut down the app-wide image proxy from a dialog.
- Groups: a panel belongs to at most one group; moves happen only through explicit checkbox actions, never silently. Donors left with <2 members go to `_auto_removed`; `_dropped()` = `_removed | _auto_removed`. `_signature` ignores `row_groups` unless `baseline_mode == "custom"`. Zero/one selections open the checklist, never silently select all. `Ctrl+Shift+A` stays Auto Layout (the split button arrow adds Align Plot Areas).
- `PlotAreaView`: `set_area` never emits; only user marking writes `source_digest` (fingerprint verified); preserve `_drawn` (identical redraw still emits). Marking is not cropping. "Fit plots within cells" is a suggestion shown for `reduced_to_fit`, not a repair.
- Schema 2: `Cell.plot_area` (normalized to full source before crop/rotation) + `PlotAlignmentGroup`. `reference` sizing falls back to fit when the exact size would clip, recording a non-blocking `reduced_to_fit` in `notices` (not `issues`); only `no_space` overflow blocks. Only plot height is matched; aspect preserved. Suggestions: `plot_area_detect.py` (native render → matplotlib SVG axes → raster heuristic).
- `resolve_image_placements(project, layout_result=None, strict=False)` is the shared placement API (no mutation; strict raises `PlotAlignmentError`). All five figure exports validate strictly before file dialogs; raw source export and saving stay available — **never add a global save guard** for alignment problems. Remove alignment keeps marks.
- SVG export needs explicit per-layer clip paths with unique IDs (QSvgGenerator drops painter clipping); verify exported SVGs in a browser, not only QtSvg/MuPDF. PDF stamping keeps source PDFs vector.
- Tutorial tests locate the split button via `_auto_layout_button`, not `toolbar.widgetForAction(_act_auto_layout)`.

## Native plots in ILM
- Applied documents are immutable content-addressed `plot-<sha256>.ilmplot.svg` under `plot_documents_root()` (never swept). `SetPlotDocumentCommand` resolves the cell by id and stamps `source_digest`. ILM launches the Plot Editor detached (`QProcess.startDetached`; the `exec()` adapter returns Rejected). Store files open via a `--ilm-copy` detached tab; user files open linked.
- Saved-SVG look is the default; reflow is opt-in (user rule): `Cell.plot_reflow` (schema 5; schema ≤4 migrate to True). `editable_plot.plot_reflows()` is also False when `aspect_ratio_locked` or the cell is in an alignment group. Off → stored snapshot verbatim, scaled like a picture. The "Reflow ON" chip is screen-only (never exported). Reflowing cells render via `render_document_fitted` at real mm size; typography is never shrunk. `resolve_plot_row_frames` aligns axes heights across a grid row. Auto Layout uses the same predicate (reflowing grid leaves share a neutral 4:3).
- Inset frames size from `pip_aspect.pip_source_aspect` (source dimensions, before thumbnails load).

## Plot Editor (`src/plot_editor/`, core in `packages/ilmplot`)
- User rules: the editor must be "reliable, efficient, professional, restrained, and low cognitive load". Unstyled plots use **matplotlib defaults** (tab10, 10/12 pt, etc.); implicit defaults apply to existing files, explicit stored values are kept.
- Core (`ilmplot.document/render/stats/mathtext/messages/bridge`) is Qt-free and ILM-free; `ilmplot/__init__` imports no matplotlib at import time. `src/plot_editor/{document,render,stats,mathtext,matplotlib_bridge}.py` are `sys.modules` aliases. `src/__init__.py` prepends `packages/ilmplot/src` to `sys.path`; keep that path in PyInstaller config of `build_onefile.py`, `build_onefile_macos.py`, `build_installer_windows.py`.
- File `*.ilmplot.svg`: SVG + JSON in `<metadata id="ilm-plot-document">` + editor-owned `<metadata id="ilm-plot-worksheet">` (ignored by ILM). Strict parsing (unknown fields, non-finite values, duplicate ids, future schema → error), never eval/pickle; `<!ENTITY` rejected; deterministic SVG bytes. Saves re-parse before atomic write.
- Compatibility: document schema stays 1. New optional fields are omitted when default/None so old files stay **byte-identical**; new features get a capability id (`document.CAPABILITIES` / `plot_file.WORKSHEET_CAPABILITIES`) stamped into `requires`, and readers raise `PlotVersionError` for unknown ones. Keep worksheet `requires` stamps in sync with new override fields. Worksheet node is schema 2 only when `overrides` are emitted. A bad/newer worksheet node never blocks opening (sheet rebuilt, tab detached). `build/baseline_capture.py` checks byte identity of legacy docs.
- QtSvg quirks: ignores clipPath → renderer clips in data space (`clip_series_to_view`, `clip_polygon_to_view`); draws `stroke-width:0` as a hairline → zero-width strokes must be suppressed.
- `ilmplot.savefig` maps supported matplotlib artists (lines, scatter, errorbars, bars, `ax.hist`, step lines, `imshow`/`pcolormesh` heatmaps, `fill_between` bands, `axvspan`/`axhspan`) to a native file; anything unrepresentable falls back to plain SVG + `FallbackWarning` (`strict=True` raises).
- Editor model: tabbed `PlotTab`s; worksheet model (`worksheet.py`) emits granular events (no 'reset'), column letters are positional. Edits are `PlotOverrides` (None = not overridden); `update_overrides` deep-copies and rolls back on error, and every edit is an 'Edit Plot' undo entry. Preview, save and export all go through the native renderer (preview == saved == ILM). Committed worksheet edits re-plot live.
- Content vs formatting: annotations, brackets, bands, spans and fills are content — they survive Reset formatting and are never captured by style presets. Presets (`presets.py`) are formatting only; preset/theme roots use a fixed folder name, never the translated app name. Saved custom themes snapshot `palette_colors`.
- Figure size is document geometry (`figure_size.py`); one resize = one undo via `worksheet.record_external_edit`.
- Focus: worksheet shortcuts act only while the worksheet (or its overlay/editor) has focus; `PlotCanvas` takes focus on press and handles Delete for notes/fills. The title panel getter must be `lambda: tab.plot_title` (a `None` getter erases the title).
- Styling: ILM chrome via `src.app.theme`/`icons`/`motion`; editor-only widgets use token templates in `chrome.py` — no literal colours, never restyle ILM chrome.
- i18n: language read once from ILM's saved setting; strings in `src/plot_editor/i18n.py` (en/zh); plot/file content is never translated.
- Kinds: line family, `violin` family (`ViolinOptions.body` violin/none(box)/bar), `histogram`, `ridgeline`, stacked/grouped columns and horizontal bars, `heatmap`, `step_line`. A plain violin with no overrides keeps `doc.violin = None`. Error bars: a `yErr` column belongs to the nearest Y to its left; `yErrPlus`/`yErrMinus` are asymmetric.

## Updates and distribution
- `src/utils/distribution.py::install_channel()` → `store | installer | macos | source` (`ILM_INSTALL_CHANNEL` overrides). **Store builds must not offer any non-Store update path** (policy 10.2.5): no startup check, no website/GitHub links — only the Store note/button.
- `latest.json` may carry `windows_installer: {url (https), sha256, size}`; without it the UI falls back to link-only. Installer downloads stage to `CacheLocation/updates` with size + SHA-256 verify (re-verified before install). Skipped version: QSettings `updates/skipped_version`.

## Licensing and release
- `licenses/` holds vendored full texts + `origins.json` (source + SHA256). Never paraphrase license text; re-vendor exact upstream files on version bumps. Missing license files are a hard error unless `build_licenses.FALLBACKS` matches exact version + recorded SHA256. `licenses/native/**` entries need a `binding` (`distribution` or `runtime_file`) and every entry is hash-verified; tests staging licenses with mocked distributions must filter out `component` records.
- `python build_licenses.py` stages `build/licenses-*`; the source zip is application source only. `source_status` stays `incomplete` and `--check-release` exits 2 while items are pending — staging output is not release clearance.
- `SOURCES.md` is generated by `build_source_index.py` (`collect`/`render`/`check`) — never edit the Markdown or upgrade recorded status strings by hand. `licenses/sources.json` must not contain `application_source_sha256` (self-referential). Regenerate on any app/dependency version change.
- Store/MSIX: isolated onedir `python build_installer_windows.py --onedir-only --output-root build\store-candidate-<unique>` (new dir; isolated PATH, no blanket Qt/matplotlib collection). `python build_msix.py --bundle <out>\dist\ImageLayoutManager --output <new-dir> --identity-name … --publisher CN=… --publisher-display-name … [--makeappx <path>]` (no `--makeappx` → layout only). MakeAppx can come from the `Microsoft.Windows.SDK.BuildTools` NuGet under `build/sdk-tools-*`; verify its signature. `audit_release.py inventory|sources` outputs stay under ignored `build/`; RECORD matches are provenance candidates, not proof.
